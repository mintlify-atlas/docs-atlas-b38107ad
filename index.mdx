Allipos is a mobile-first Progressive Web App that lets children and young learners — including those with learning barriers or difficulty with mental math — manage sales, accept payments, and calculate change independently at school fairs (*kermeses*). Its gamified, Duolingo-style interface guides users through every transaction in four simple steps, with real coin and bill photos, voice narration in Spanish, and full offline support.

## What makes Allipos different

Allipos was designed from the ground up to reduce cognitive load for young cashiers. Every design decision — from the oversized 3D tactile buttons to the automatic voice narration — follows inclusive, gamified UX principles inspired by Duolingo.

## Get up and running

<Steps>
  <Step title="Clone and install">
    Clone the repository and install the only dev dependency (Vite).
    ```bash
    git clone https://github.com/soymatudev/allipos.git
    cd allipos
    npm install
    ```
  </Step>
  <Step title="Start the dev server">
    Launch Vite's dev server and open the local URL in a browser or scan the LAN IP from a phone.
    ```bash
    npm run dev
    ```
  </Step>
  <Step title="Add products">
    Go to the **📦 Productos** tab to review the pre-loaded catalog or add your own items with photos from the camera roll.
  </Step>
  <Step title="Start selling">
    Switch to the **🛒 Cobrar** tab and tap a product to begin the guided 4-step checkout flow.
  </Step>
</Steps>

<Tip>
  To use Allipos offline at a fair, build the production bundle (`npm run build`), deploy it to Vercel or any static host, and install it as a PWA from Chrome on your phone. See [PWA Installation](/pwa-install) for the full walkthrough.
</Tip>
